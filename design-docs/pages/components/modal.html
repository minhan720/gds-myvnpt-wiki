Usage

HTML 
<!-- Modal Overlay/Backdrop -->
<div class="modal-overlay is-open">
    <!-- Modal Container -->
    <div class="modal modal-md">
        
        <!-- Header -->
        <div class="modal-header">
            <h3 class="modal-title">Modal Title</h3>
            <button class="modal-close" aria-label="Close">
                <!-- SVG Close Icon -->
            </button>
        </div>

        <!-- Body -->
        <div class="modal-body">
            <p>Modal content goes here...</p>
        </div>

        <!-- Footer -->
        <div class="modal-footer">
            <button class="btn btn-tertiary btn-md">Cancel</button>
            <button class="btn btn-primary btn-md">Confirm</button>
        </div>

    </div>
</div>
JS 
// Simple toggle logic example
function openModal(id) {
    document.getElementById(id).classList.add('is-open');
}

function closeModal(id) {
    document.getElementById(id).classList.remove('is-open');
}

Props Reference

Class / Role Description
.modal-overlay The backdrop layer. Add .is-open to display the modal.
.modal The main dialog container. Holds header, body, and footer.
.modal-sm | -md | -lg Size modifier classes applied to .modal. Controls max-width. Default is unbounded or ~600px depending on logic.
.modal-header Header section, typically flex container for Title and Close button. Has bottom border.
.modal-body Scrollable content area with padding.
.modal-footer Action area at the bottom, right-aligned. Has top border and slightly darker background.
