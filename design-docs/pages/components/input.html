Usage

HTML 
<!-- Include input.css -->
<link rel="stylesheet" href="styles/components/input.css">

<!-- Standard Input Structure -->
<div class="input-wrapper">
  <label class="input-label input-label-required">Email Address</label>
  <div class="input-container">
    <input type="email" class="input-field" placeholder="name@vnpt.vn">
  </div>
  <div class="input-help-text">We will never share your email.</div>
</div>

Accessibility Considerations

  • Always associate the <label> with the <input> using for and id attributes.
  • The default focus state utilizes a solid 2px ring with strong contrast to visibly highlight the active input area for keyboard users.
  • When using the is-error state, ensure the descriptive help text clearly states how to fix the error, rather than just relying on color conveying the error.
