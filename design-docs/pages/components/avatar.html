Avatar

An image element with a fallback for representing the user or an entity.

HTML 
<div class="avatar avatar-md avatar-circle">
  <img class="avatar-image" src="https://images.unsplash.com/photo-1534528741775-53994a69daeb?auto=format&fit=crop&w=100&q=80" alt="User Name">
</div>

Installation & Usage

Installation

HTML 
<link rel="stylesheet" href="styles/components/avatar.css">

Usage

Use the avatar base class with avatar-image or fallback content.

Examples / Variants

Image & Fallback

Avatar supports image, text initials, and icon fallbacks.

VQ
HTML 
<!-- Image Avatar -->
<div class="avatar avatar-md avatar-circle">
  <img class="avatar-image" src="..." alt="User profile photo">
</div>

<!-- Initials Fallback -->
<div class="avatar avatar-md avatar-circle">
  <div class="avatar-fallback">VQ</div>
</div>

<!-- Icon Fallback -->
<div class="avatar avatar-md avatar-circle">
  <div class="avatar-fallback">
    <svg width="18" height="18" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">
      <path d="M20 21v-2a4 4 0 0 0-4-4H8a4 4 0 0 0-4 4v2"></path>
      <circle cx="12" cy="7" r="4"></circle>
    </svg>
  </div>
</div>

Sizes & Status

Avatars can be sized from sm to xl, and incorporate status indicators.

A
HTML 
<!-- Small with Online Status -->
<div class="avatar avatar-sm avatar-circle">
  <img class="avatar-image" src="..." alt="User">
  <span class="avatar-status status-online"></span>
</div>

<!-- Medium with Away Status -->
<div class="avatar avatar-md avatar-circle">
  <img class="avatar-image" src="..." alt="User">
  <span class="avatar-status status-away"></span>
</div>

<!-- Large with Busy Status -->
<div class="avatar avatar-lg avatar-circle">
  <img class="avatar-image" src="..." alt="User">
  <span class="avatar-status status-busy"></span>
</div>

<!-- Extra Large Fallback with Offline Status -->
<div class="avatar avatar-xl avatar-circle">
  <div class="avatar-fallback">A</div>
  <span class="avatar-status status-offline"></span>
</div>

Shapes

Avatars can be rendered as full circles or slightly rounded squares.

HTML 
<!-- Circle Shape (Default) -->
<div class="avatar avatar-lg avatar-circle">
  <img class="avatar-image" src="..." alt="User">
</div>

<!-- Rounded Square Shape -->
<div class="avatar avatar-lg avatar-rounded">
  <img class="avatar-image" src="..." alt="User">
</div>

Design Specifications

Element Property Token / Value
.avatar-sm Width & Height 24px
.avatar-md Width & Height 32px
.avatar-lg Width & Height 40px
.avatar-xl Width & Height 56px
.avatar-circle Border Radius var(--br-full) / 9999px
.avatar-status Size 30% of Avatar's Dimensions

API Reference

Props

Class Type Default Description
size class sm | md | lg | xl md Defines the square dimension of the avatar element.
shape class circle | rounded - Determines border radius. circle sets a full curve (9999px), rounded sets an 8px curve.
.avatar-status component - Small indicator circle placed at the bottom-right corner. Paired with status-[color].
status class online | busy | away | offline - Modifies the background color of the .avatar-status component.
