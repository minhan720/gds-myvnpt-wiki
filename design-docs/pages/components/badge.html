Badge

A small, non-interactive visual indicator used to highlight status, attributes, or numeric quantities.

New Feature
HTML 
<span class="badge badge-primary badge-md">New Feature</span>

Installation & Usage

Installation

HTML 
<link rel="stylesheet" href="styles/components/badge.css">

Usage

Use the badge base class along with variant, size, and shape modifiers.

Examples / Variants

Color Variants

Badges come in different semantic colors to represent state.

Neutral Primary Success Warning Error

Rounded Shape

Use the badge-round modifier to reduce the border radius (e.g. 8px).

HTML 
<span class="badge badge-round badge-success badge-md badge-icon-left">
  <svg viewBox="...">...</svg>
  Label
</span>

Design Specifications

Element Property Token / Value
.badge-sm Height / Padding / Font 20px / 6px horizontal / 12px text
.badge-md Height / Padding / Font 24px / 8px horizontal / 14px text
.badge-lg Height / Padding / Font 28px / 12px horizontal / 14px text
.badge (Pill) Border Radius var(--br-full) / 9999px

API Reference

Props

Class Type Default Description
variant class neutral | primary | success | warning | error neutral Dictates the background, text, and border color based on semantic tokens.
size class sm | md | lg md Defines the height, padding, and font size.
shape class (none) | badge-round (none) - Pill Defines the border radius. Pill is fully rounded, Round is slightly rounded (8px).
icon classes badge-icon-left | badge-icon-right none Provides appropriate spacing for inline SVGs on the left or right side of the text.
