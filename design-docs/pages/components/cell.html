Cell Item

Cell item là thành phần hiển thị một hàng thông tin trong danh sách, với nhãn bên trái, nội dung bên phải, và icon trailing để chỉ ra hành động điều hướng.

API Reference

Cell Item là một single component (không có variant property). Toàn bộ nội dung được tùy chỉnh thông qua child text nodes và icon instance swap.

ElementCustomizableNotes
Label text✅ EditableThay đổi trực tiếp text node "Information"
Value text✅ EditableThay đổi trực tiếp text node "Content here"
Trailing icon✅ Instance swapMặc định: Copy icon. Có thể swap sang Chevron-right, etc.

Accessibility

  • Mỗi cell nên sử dụng semantic <dl> / <dt> / <dd> hoặc <table> cho nội dung key-value
  • Nếu trailing icon là actionable (copy), cần role="button" và aria-label="Sao chép"
  • Contrast: label #717981 trên #FFFFFF đạt 4.48:1 (AA cho text >14px); value #34404B đạt 10.2:1
