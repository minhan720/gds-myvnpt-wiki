Accessibility

  • Checkbox: sử dụng <input type="checkbox"> native hoặc role="checkbox" với aria-checked
  • Radio: sử dụng <input type="radio"> trong <fieldset> + <legend>
  • Disabled states: thêm aria-disabled="true", không chỉ visual
  • Label phải liên kết với input qua for/id hoặc wrapping <label>
  • Keyboard: Space toggle checkbox; Arrow keys navigate radio group
  • Focus visible: outline rõ ràng khi tab-focused
