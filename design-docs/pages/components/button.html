Button

Displays a button or a component that looks like a button.

HTML 
<button class="btn btn-primary btn-md">Button</button>

Installation & Usage

Installation

HTML 
<link rel="stylesheet" href="styles/components/button.css">

Usage

Use the btn base class along with variant and size modifiers.

Examples / Variants

Primary

The default high-emphasis button for principal actions.

HTML 
<button class="btn btn-primary btn-md">Label</button>

Secondary

For medium-emphasis secondary actions. Has a brand-colored border and text.

HTML 
<button class="btn btn-secondary btn-md">Label</button>

Tertiary

A low-emphasis variant without border or background, keeping brand-colored text.

HTML 
<button class="btn btn-tertiary btn-md">Label</button>

Text

Ghost-like button using neutral text color instead of brand.

HTML 
<button class="btn btn-ghost btn-md">Label</button>

Underline

An inline text button with an underline, representing the Link hierarchy.

HTML 
<button class="btn btn-link btn-md">Label</button>

With Icon

Add btn-icon-left or btn-icon-right to correctly space an inline SVG.

HTML 
<!-- Icon Left -->
<button class="btn btn-primary btn-md btn-icon-left">
  <svg ...></svg>
  Label
</button>

<!-- Icon Right -->
<button class="btn btn-primary btn-md btn-icon-right">
  Label
  <svg ...></svg>
</button>

Icon Only

Use btn-icon-only for an evenly-padded square action button, ensuring an aria-label is provided.

HTML 
<button class="btn btn-secondary btn-sm btn-icon-only" aria-label="Settings">
  <svg ...></svg>
</button>

Design Specifications

Element Property Token / Value
.btn-sm Height / Padding / Font 32px / 8px horizontal / 14px text
.btn-md Height / Padding / Font 40px / 16px horizontal / 16px text
.btn-lg Height / Padding / Font 48px / 24px horizontal / 16px text
.btn Border Radius var(--br-full) / 9999px
Icon & Text Spacing (Gap) var(--space-1x) / 4px

API Reference

Props

Class / Prop Type Default Description
variant primary | secondary | tertiary | ghost | link primary Determines button Hierarchy (Primary, Secondary, Tertiary, Text, Underline).
size sm | md | lg md Controls button sizes reflecting exact Figma component variants.
btn-icon-left | btn-icon-right | btn-icon-only modifier class none Adds margin when an icon SVG is used inside the button.
btn-full modifier class false Stretches button width: 100%.
