# Super UX Phase 3: Spec Design Workflow

**Vai trò thực hiện:** UX Designer & Writer

**Mục tiêu:** Trực quan hóa Ý tưởng thành Luồng tương tác, Copywriting, Docs.

1. **Kế thừa Blueprint:** Lấy Idea từ file `empathy_strategy_blueprint.md` đã được Boss thông qua ở Phase 2.
2. **Dựng Xương (UX Flow):** Vẽ các biểu đồ trạng thái Mermaid của màn hình hoặc Step-by-step logic text.
3. **Đắp Da, Đắp Thịt (UI Copywriting & Specs):** 
   - Biến các ngôn từ logic thành Copywriting thấu cảm nhờ `/ux-writing`.
   - Trám toàn bộ các Edge Cases (Lỗi API, Xử lý Exception).
4. **Self-Review:** Tự kiểm tra xem luồng có bị lỗi ngõ cụt (Dead-end) nào không? Copywriting có ngắn gọn chưa?
5. **Xuất Bản Specs:** Ghi vào 2 cụm file `ux_flow_mermaid.md` và `ui_copywriting_specs.md`.
6. **🛑 CHỜ PHÊ DUYỆT CUỐI (HITL 3):** Trình bày Báo cáo Nghiệm thu tổng kết gửi Boss duyệt đóng dự án. Lắng nghe Feedback của Boss nếu có để tinh chỉnh Specs (Technical Writer mode).
